01RECEPTION / CHECK-IN

まずはここから。
受付・入庫エリア。

ご来店されたお客様のご要望や車の状態を伺い、整備スタッフへつなぐ入口です。整備の仕事は、工具を握る前の「何に困っているのか」を知るところから始まります。

CHECK POINT

お客様との距離感や、フロントと整備スタッフの連携にも注目。

02MAIN PIT

整備士のメインステージ。
整備ピット。

車検・法定点検・一般整備などを行う工場の中心エリア。さまざまな車種が入庫するため、日々の仕事を通して幅広い経験を積むことができます。

CHECK POINT

作業スペースの広さや、車両同士の間隔など「働きやすさ」も見てみてください。

03INSPECTION / DIAGNOSIS

原因を見つける。
点検・診断の現場。

異音や不具合など、車の状態を確認しながら原因を特定していきます。目視だけでなく診断機器も活用し、必要な整備を判断する、整備士の経験と知識が活きる仕事です。

CHECK POINT

先輩に相談しながら進める場面も多く、チームで知識を共有することも大切です。

04TOOLS / EQUIPMENT

仕事を支える、
工具と設備。

安全で正確な整備には、使いやすい工具や設備が欠かせません。日々使う道具がどのように整理され、どんな環境で作業しているのかも、工場選びでは大事なポイントです。

CHECK POINT

工具の整理整頓や作業導線は、工場の仕事のしやすさが表れるポイントです。

05TEAM WORK

一人で抱え込まない。
現場のチームワーク。

整備の現場では、判断に迷ったときや難しい作業に向き合うとき、スタッフ同士で声を掛け合うことがあります。経験年数に関係なく相談しながら進めることが、品質と成長につながります。

CHECK POINT

設備だけでなく「誰と働くのか」も、ぜひ工場見学で見てほしいポイントです。
